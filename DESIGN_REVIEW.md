# Концепция решения: PocketGoogle Search Index

## Название проекта
PocketGoogle Search Index

## Цель
Реализовать структуру данных для быстрого поиска слов в документах.

## Идея решения
Для хранения индекса используется словарь:

слово -> id документа -> список позиций слова в документе

Такой подход позволяет быстро:
- находить все документы, где встречается слово;
- находить позиции слова в конкретном документе;
- удалять документ из индекса.

## Основные методы

### Add
Метод проходит по тексту документа один раз, выделяет слова по разделителям и сохраняет начальные позиции каждого слова.

### GetIds
Метод возвращает все id документов, где найдено указанное слово.

### GetPositions
Метод возвращает все позиции, с которых слово начинается в выбранном документе.

### Remove
Метод удаляет документ из индекса. Для этого сохраняется исходный текст документа, затем при удалении он снова разбирается на слова, и id документа удаляется из индекса по каждому найденному слову.

## Разделители слов
Используются разделители:
пробел, точка, запятая, восклицательный знак, вопросительный знак, двоеточие, дефис, перевод строки.

## Проверка
Проверяется:
- добавление одного документа;
- добавление нескольких документов;
- поиск id документов по слову;
- поиск позиций слова;
- удаление документа;
- повторное добавление документа с тем же id.

## Результат самопроверки
Концепция соответствует требованиям README. Решение использует Dictionary для быстрого доступа к словам и документам.
